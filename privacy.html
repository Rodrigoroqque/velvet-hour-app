velvet hour

Privacy policy

Last updated: October 11, 2026

velvet hour is a private, single-user tool. It is used only by the owner of the YouTube channel it connects to. It is not offered to the public.

YouTube API Services

This tool uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the tool accesses

With the channel owner's authorization through Google sign-in, the tool accesses data of that owner's own channel:

  • channel information and statistics;
  • video metadata, such as title, description, tags and visibility;
  • analytics reports, such as views, watch time and audience retention;
  • comments on the channel's own videos.

How the data is used

The data is used only to show the channel owner their own numbers and to apply the metadata changes the owner asks for and confirms.

Storage and sharing

  • The authorization token is stored only on the owner's own computer.
  • Data fetched from the API is shown to the owner and is not kept on any server.
  • No data is sold, shared with or transferred to third parties.
  • The tool does not use cookies and does not track visitors of this page.

Revoking access

Access can be revoked at any time on the Google security settings page, at myaccount.google.com/permissions. Once access is revoked, the tool can no longer reach the channel, and the stored token stops working.

Contact

Questions about this policy can be sent by opening an issue on the project page.
