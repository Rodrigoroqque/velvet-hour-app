velvet hour

A private channel tool

velvet hour is a small, single-user tool. It connects to one YouTube channel with the owner's permission, so the owner can read the channel's own analytics and edit the metadata of their own videos from their computer.

What it does

  • Reads channel and video statistics, including watch time and audience retention.
  • Reads comments on the channel's own videos.
  • Updates the title, description, tags, visibility and schedule of the channel's own videos, only when the owner confirms each change.

What it does not do

  • It does not upload videos.
  • It is not offered to the public and has no sign-up.
  • It does not sell, share or transfer any data.

This tool uses YouTube API Services. See the privacy policy for how data is handled.
